# Smart Escape

Name: Smart Escape Team
Registration Number: 12345

## Live Demo
https://smart-escape-demo.example.com

## Features
- JSON import
- Interactive building map
- Weighted shortest path
- Dynamic hazard simulation
- Automatic rerouting
- Reset
- Bangla/English

## Bonus Features
- Responsive design
- Micro-animations for interactions
- Dynamic edge routing animation

## How to Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Known Issues
- Large map zooming is not fully implemented yet; requires scrolling for large maps.

## AI Tools Used
- Antigravity IDE

## Most Useful Prompt
"Implement a Dijkstra shortest-path function in JavaScript for an undirected weighted graph. It must ignore blocked nodes, blocked edges, and closed exits, return the path and total cost, and support deterministic tie-breaking."
